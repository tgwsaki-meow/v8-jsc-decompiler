### Operand types

* added: `kEmbeddedFeedback`
* removed: none

`kEmbeddedFeedback`: kFixedUnsignedShort, baseSize 2, fixed width, unsigned
`kFeedbackSlot` (14.4.258.16): kScalableUnsignedByte, baseSize 1, scalable

**Why this matters for a decoder.** A scalable operand grows with the `Wide`/`ExtraWide` prefix; a fixed one does not. Any opcode that moved from a scalable to a fixed operand changes its encoded length under a prefix, so decoding one version with the other version's table desynchronises the instruction stream from that point on.

### Note on the index: 504 vs 647

`scratch/recon/VERSION_PLUGGABILITY.md` §3.4 reported this divergence at index **504**.
That figure was measured against a root expansion that silently dropped the
**142** `V8_INTL_SUPPORT` internalized strings (it kept the empty `#else` body of the
doubly-defined `INTERNALIZED_STRING_LIST_GENERATOR_INTL`) and also lost
`close_parenthesis_string` to a paren matcher that counted the `)` inside the
string literal `")"`. The divergence is the *same pair of roots*; only the index moved:

```
corrected first divergence            647
minus 142 V8_INTL_SUPPORT strings      -142
minus close_parenthesis_string         -1
                                     = 504   <- the previously reported figure
```

Verified by pruning exactly those roots from both corrected lists, which puts the
first divergence back at **504**. The 647 figure is the correct one for the real
`intl+wasm` build: it agrees positionally with `StaticReadOnlyRootsPointerTable`
at 1045/1045 (14.4.258.16) and 1049/1049 (14.6.202.34).

**Consequence.** Root indices are not portable across these two tags. A
serialized `kRootArray` reference with index >= 647 names a different root in
each version.

## What a decoder must do differently

1. Use the per-tag `operands.json`: the six compare bytecodes change operand
   width, so instruction lengths differ under `Wide`/`ExtraWide`.
2. Use the per-tag `roots.json`: indices from 647 up name different roots.
3. Use the per-tag `static-roots.json`: compressed read-only addresses move.
4. `serializer-tags.json`, `intrinsics.json`, `layouts.json` and `constants.json`
   happen to be interchangeable between these two tags, but nothing guarantees
   that for the next pair, so they stay per-tag too.
